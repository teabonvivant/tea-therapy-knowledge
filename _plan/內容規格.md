# 茶療知識庫｜內容規格（寫作代理必讀）

網站：茶療知識庫（姊妹站：普洱茶知識庫、六大茶知識庫）。主題：茶與慢性病、日常保健——以中醫養生及茶療角度出發，配合西醫及營養學的科學解釋。讀者：香港成年讀者、茶友、照顧長者的家人。

## 鐵律（違反任何一條即不合格）
1. **不可虛構**：研究、作者、年份、期刊、數字、古籍原文、專家、病人、引語，一律不可編造。每個研究數字必須有你親自用 WebSearch／WebFetch 打開核實過的來源（PubMed、期刊頁、官方機構）。找不到就不寫該數字。
2. **不作療效宣稱**：茶不是藥。不可寫「治療／根治／降血糖藥替代／抗癌」。只寫「研究觀察到…相關」「試驗中平均下降約…」，並講清研究類型（細胞／動物／觀察性／隨機對照／薈萃分析）及證據強度。香港《不良醫藥廣告條例》（第 231 章）列明的疾病（如糖尿病、高血壓、心臟病、癌症等）尤其不可寫成「預防或治療」的宣傳語氣。
3. **病人先看醫生**：每頁有「要小心的人」，指出藥物相互作用、孕期、腎病、貧血、胃病等；提醒正在服藥者先問醫生或藥劑師，不可自行停藥。
4. **中醫部分**：只引你核實過的古籍原文（要寫書名、卷／部、朝代、作者）；流傳語若出處存疑要明寫「相傳」「後世輯本引用」。證型、茶性屬傳統經驗，寫明「傳統認為」。不給處方劑量的藥方；代茶飲只寫藥食同源材料（以國家衞健委《按照傳統既是食品又是中藥材的物質目錄》為準，核實後才用），並提醒體質不合者避開。
5. **語言**：香港繁體中文、港式用詞（雪櫃、方便、馬上；不用擱、省事、一下子、冰箱、咱們）。不出粵語口語。
6. **不要 AI 腔**：禁「先說三件事」「一是…二是…三是」「值得一提／我認為／不妨／記住／總而言之／綜上所述」、對稱判斷句、每段結尾一句口號。具體先於道理，以過程代替結論；長短句交錯；可以用「你」「有位茶友」「家中長輩」製造在場感，但不冒充真人、不編造姓名。每頁 1–3 個真問句。
7. 不放外部網站以外的推銷；**正文不可有外部連結**——外部連結只放在 frontmatter 的 `sources`（網站會在頁尾「來源」區渲染）。

## 檔案格式
每頁一個 Markdown 檔，UTF-8，YAML frontmatter＋正文。正文以 `##` 作小標題（不要用 `#`）。引用用 `〔1〕`、`〔2〕` 這種標記，對應 frontmatter `sources` 的次序（第 1 條＝〔1〕）。

### 慢病專題（`site/src/content/conditions/<slug>.md`）
```yaml
---
title: 血糖                # 2–6 字，名詞為主
fullTitle: 茶與血糖、二型糖尿病
slug: blood-sugar
group: 代謝               # 代謝｜心血管｜腦與情緒｜消化｜骨與泌尿｜細胞與腫瘤
order: 1
tcmName: 消渴             # 中醫對應病名或概念，沒有就寫「—」
lede: 一句導語（25–45 字，不與首段重複）
answer: 兩三句直答（60–110 字）：目前研究能說到哪一步、不能說到哪一步。
evidence:                 # 3–6 條具體說法，各自評級
  - claim: 每日飲茶的人，日後患二型糖尿病的風險較低
    level: 3              # 4 強（多個 RCT 薈萃一致）｜3 中（大型前瞻性世代一致，或 RCT 效果小）｜2 弱（少量／結果不一）｜1 不足（只有細胞或動物）
    basis: 前瞻性世代研究薈萃分析
    sourceRef: [1]
teas:                     # 建議的茶與飲法（2–4 項）
  - name: 綠茶
    why: 一句
tcmTeas:                  # 傳統代茶飲配伍（0–3 項，只用藥食同源材料）
  - name: 桑葉茶
    mix: 乾桑葉 3 克，熱水焗 5 分鐘
    note: 傳統用法＋現代研究一句＋誰要避開
cautions:
  - 一句一個（3–6 項）
sources:
  - text: "Author A, Author B, et al. Title. Journal. 2014;100(1):1-10."
    url: https://pubmed.ncbi.nlm.nih.gov/xxxxxxx/
    kind: 薈萃分析          # 薈萃分析｜隨機對照試驗｜前瞻性世代｜系統回顧｜官方指引｜古籍｜機構資料｜動物／細胞
reviewed: 2026-10-23
---
```
正文小標題固定為（可略調字眼但次序不變）：
1. `## 中醫怎樣看`（病機、相關證型、茶性如何對應；古籍原文 1–2 句）
2. `## 研究怎樣說`（西醫流行病學、臨床試驗：研究類型、人數、結果大小、限制）
3. `## 營養學的解釋`（成分：兒茶素 EGCG、茶黃素、茶褐素、茶胺酸、咖啡因、氟、草酸等；機制；一杯茶大約含多少；與試驗劑量的距離；加糖加奶的影響）
4. `## 兩套說法在哪裏相遇`（交匯與分歧，誠實說哪裏對不上）
5. `## 一天的茶`（實際飲法：茶類、份量、時間、溫度＜65°C、配餐）
6. `## 要小心的人`（展開 cautions）
正文長度 1,800–2,600 字（中文字）。

### 其他頁面類型
- 安全（`site/src/content/safety/<slug>.md`）：frontmatter `title, fullTitle, slug, order, lede, answer, cautions, sources, reviewed`；正文自由小標題，1,000–2,000 字。
- 茶方（`site/src/content/remedies/<slug>.md`）：`title, slug, order, base（茶底）, herbs（[{name, amount}]）, method, nature（寒涼／平／溫）, suits, avoid, lede, sources, reviewed`；正文：`## 傳統用法`、`## 現代研究`、`## 怎樣泡`、`## 不適合的人`，600–1,200 字。
- 茶類（`site/src/content/teas/<slug>.md`）：`title, slug, order, nature, ferment（發酵程度文字）, color（茶湯色 hex）, compounds（主要成分＋每杯大約含量，含來源）, lede, sources, reviewed`；正文：`## 茶性`、`## 主要成分`、`## 誰適合／誰要留意`、`## 研究亮點`，900–1,500 字。

交付前自查：每個數字都能在 sources 找到；所有 URL 都打開過；沒有禁用語；字數達標。
